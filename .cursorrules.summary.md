# Cursor Rules Summary

## 🚨 CRITICAL RULES - NEVER VIOLATE

### 1. Dependency Flow (NO EXCEPTIONS)

```
✅ ALLOWED:
apps/landing    →  packages/ui
apps/chat       →  packages/types
apps/experts    →  packages/utils
apps/admin      →  packages/config

packages/ui     →  packages/utils
packages/ui     →  packages/types
packages/utils  →  packages/types

❌ FORBIDDEN:
packages/ui     →  apps/*          (NEVER)
apps/chat       →  apps/landing    (NEVER)
packages/types  →  packages/ui     (NEVER)
Any circular dependencies           (NEVER)
```

### 2. Import Paths (STRICT)

```typescript
// ✅ CORRECT
import { Button } from '@raweval/ui/button';
import type { Expert } from '@raweval/types';
import { cn, formatDate } from '@raweval/utils';
import { HeroSection } from '@/components/hero-section';

// ❌ WRONG
import { Button } from '../../../packages/ui';
import { Button } from '@raweval/ui';  // No barrel exports!
import { HeroSection } from '../components/hero-section';
```

### 3. Package Rules

**packages/types:**
- ❌ NO runtime code
- ❌ NO dependencies
- ✅ Only types and interfaces

**packages/ui:**
- ✅ Only React components
- ❌ NO business logic
- ❌ NO data fetching
- ❌ NO barrel exports (for tree-shaking)

**packages/utils:**
- ✅ Pure functions only
- ❌ NO side effects
- ❌ NO React-specific code

**packages/config:**
- ✅ Configuration only
- ❌ NO runtime code

### 4. Before Every Commit

- [ ] No cyclic dependencies introduced
- [ ] Imports use correct paths
- [ ] Code formatted (`pnpm format`)
- [ ] No linting errors
- [ ] No TypeScript errors
- [ ] Build succeeds (`pnpm build`)

## Quick Reference

```bash
# Run all apps
pnpm dev

# Run specific app
pnpm --filter @raweval/chat dev

# Add dependency to app
pnpm --filter @raweval/chat add axios

# Add dependency to package
pnpm --filter @raweval/ui add lucide-react

# Format all
pnpm format

# Build all
pnpm build
```
